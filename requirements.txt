# --- MuseTalk avatar generation (avatars/musetalk/utils/preprocessing.py) ---
# That module imports `face_recognition`, which needs the dlib backend. dlib has
# no prebuilt wheels on PyPI, so a plain `pip install face-recognition` compiles
# it from source (needs cmake + a C++ toolchain, several minutes).
# Instead install in this order, which uses the prebuilt `dlib-bin` wheel:
#
#   pip install dlib-bin face_recognition_models "setuptools<81"
#   pip install --no-deps face-recognition
#
# `--no-deps` matters: face-recognition declares `dlib>=19.7`, which pip would
# otherwise try to build from source. `dlib-bin` provides the same `dlib`
# module, but not the `dlib` distribution metadata, so the requirement is never
# considered satisfied.
# `setuptools<81` is required because face_recognition_models imports the
# removed `pkg_resources` module.
# These are installed by setup.sh; they are intentionally not listed above
# because requirements.txt cannot express the needed install order.
